# Alojamientos para viajes familiares

Skill complementaria para el sistema de asesoría de viajes.

Trabaja especialmente bien junto con:

- `planificador-viajes-familiares`
- `restaurantes-celiacos-seguros`

## Objetivo

Seleccionar alojamientos optimizando:

- zona;
- capacidad familiar;
- apartamentos frente a hoteles;
- restaurantes fiables para celíacos;
- proximidad a playa;
- piscina;
- calidad;
- disponibilidad;
- precio real.

## Instalación

Carga el ZIP como una Skill independiente en ChatGPT.
