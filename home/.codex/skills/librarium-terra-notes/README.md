# Librarium Terra — Notas

Skill para generar y mantener notas de la bóveda Obsidian `Librarium_Terra`.

## Modos

- **Modo local:** con acceso directo a la bóveda, consulta la estructura y las notas reales antes de clasificar y puede escribir directamente.
- **Modo externo:** sin acceso local, utiliza `references/Librarium_Terra - Estructura y normas.md` y genera un archivo `.md` descargable.
- La estructura puede evolucionar: se prefieren carpetas existentes, pero se permiten nuevas categorías duraderas cuando estén justificadas.

## Estructura

```text
librarium-terra-notes/
├── SKILL.md
└── references/
    └── Librarium_Terra - Estructura y normas.md
```

## Instalación

Sube el ZIP desde la interfaz de Skills de ChatGPT.

## Pruebas recomendadas

1. `Convierte esta conversación en una nota para Librarium Terra.`
2. `Crea una guía general de Git rebase para mi bóveda.`
3. `Documenta la configuración de Jellyfin de mi HomeLab.`
4. `Crea una nota sobre un tema que todavía no tenga una carpeta clara.`
5. En modo local: `Busca si ya tengo una nota sobre X y actualízala si corresponde.`
